# threejs-journey

My Three.js learning journey — experiments, exercises, and small 3D scenes collected along the way.

## Why this repo

Learning WebGL/Three.js by building. Each folder is a self-contained experiment: geometry, materials, lighting, animation, shaders, cameras, controls — from rotating cubes to interactive scenes.

## Running an experiment

Most experiments are plain HTML + ES modules with Three.js from a CDN — open the folder's `index.html` via a local server:

```bash
npx serve .
```

or with Vite-based experiments:

```bash
npm install
npm run dev
```
